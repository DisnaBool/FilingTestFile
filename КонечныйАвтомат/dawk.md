# Конечный автомат

## Определение
Конечный автомат — это модель, в которой система:
- находится только в одном состоянии из конечного набора;
- принимает входные события;
- переходит между состояниями по строго заданным правилам.

---

## Виды конечных автоматов

### Детерминированный автомат
Для каждого состояния и входного события существует ровно один возможный переход.  
Поведение системы полностью определено.

### Недетерминированный автомат
Для одного состояния и входного события может существовать несколько возможных переходов.  
Система теоретически может выбрать любой из них.

---

## Описание реализации

Реализована модель управления кондиционером.

Состояния:
- OFF — устройство выключено
- FAN_ONLY — работает только вентиляция
- COOL — режим охлаждения
- HEAT — режим обогрева

События:
- POWER — включение или выключение
- MODE — переключение режима

Принцип работы:
- система всегда находится в одном состоянии;
- при нажатии POWER:
  - если состояние OFF — происходит включение и переход в FAN_ONLY;
  - если состояние любое другое — происходит переход в OFF;
- при нажатии MODE:
  - FAN_ONLY → COOL;
  - COOL → HEAT;
  - HEAT → FAN_ONLY;
  - в состоянии OFF переход отсутствует;
- переходы выполняются строго по заданным правилам без исключений.

---

## Таблица переходов

| Текущее состояние | POWER       | MODE        |
|------------------|------------|-------------|
| OFF              | FAN_ONLY   | —           |
| FAN_ONLY         | OFF        | COOL        |
| COOL             | OFF        | HEAT        |
| HEAT             | OFF        | FAN_ONLY    |
